# QR para pegatinas

Apunta a https://davidbf1.github.io/querencia/ (la web con la lista de espera). Esta carpeta no se publica en la web.

- `querencia-qr.svg`: vectorial, para la imprenta (escala sin perder calidad).
- `querencia-qr.png`: 1640 × 1640 px, solo el código.
- `pegatina-6cm.png`: pegatina de 6 × 6 cm a 300 ppp con el nombre y el texto "Escanea y apúntate a la lista de espera".

Para imprimir: tamaño mínimo del código 2,5 cm de lado; respeta el margen blanco alrededor; mejor papel mate (el brillo dificulta escanear).

Esta dirección seguirá funcionando aunque la app web pase a un dominio .com, porque la landing vive en este repositorio y no cambia de sitio. Si algún día cambias la dirección de la landing, regenera el QR antes de imprimir más.
